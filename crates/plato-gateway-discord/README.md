# Plato Gateway Discord

Discord REST, command, WebSocket, and daemon-bridge runtime for Plato Agent.

The `plato-agent` package retains configuration admission, startup composition,
the public compatibility wrapper, and the installed `plato-gateway-discord`
binary. This crate consumes only resolved gateway inputs and talks to an
already-running `plato-agentd`.
